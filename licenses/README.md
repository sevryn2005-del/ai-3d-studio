# 라이선스 전문

배포본(Windows 설치 프로그램의 엔진 폴더)에 함께 들어가는 라이선스 전문. 어떤 구성 요소에 해당하는지는 `THIRD_PARTY_NOTICES.md` 참고.

| 파일 | 대상 |
|------|------|
| `LGPL-2.1.txt` | Open CASCADE Technology (LGPL-2.1 + OCCT 예외) |
| `LGPL-3.0.txt` | casadi (LGPL-3.0+) |
| `GPL-3.0.txt` | LGPL-3.0 이 참조하는 GPL-3.0 본문 |

OCCT 예외 문구와 소스 입수 방법: https://dev.opencascade.org/resources/licensing ,
casadi 소스: https://github.com/casadi/casadi . 두 라이브러리는 설치 폴더의 개별 DLL 로 들어가며 사용자가 교체할 수 있다.
