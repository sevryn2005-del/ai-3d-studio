# 로드맵: 누구나 부담 없이 쓰는 부품 설계 + 자유 모델링

목표: 솔리드웍스·인벤터(부품·조립·도면)와 블렌더(자유 모델링·렌더)의 주요 기능을 **비전문가도 쉽게**, **무료로** 쓰게 한다.
차별점은 기능 개수가 아니라 **말로 시키거나(AI, 본인 키) 숫자·드래그로 쉽게 고칠 수 있는 것**과 **로컬 실행·오픈소스(GPL-3.0-or-later)**.

원칙 (CLAUDE.md): 로컬 우선, AI 없이도 모든 편집 가능, 웹·Windows 같은 기능, 모든 변경은 명령 경로, 두 엔진 공유 픽스처 검증,
GPL-3.0 호환 의존성만. 큰 오픈소스(블렌더·FreeCAD)는 코드를 복사하지 않고 엔진처럼 호출하거나 라이브러리로 연결.

## 현재 (2026-11-03)

| 영역 | 있는 것 |
|------|---------|
| 부품 | 기본 도형, 스케치(사각형·원·다각형), 구속 11종·자유도, 돌출(±), 기준 평면 XY·XZ·YZ, 면 위 스케치, 불리언, 박스 필렛·모따기, 관통 구멍 |
| 공통 | AI 자연어 명령(BYOK·비용 표시), 실행 취소, 로컬 저장(.ai3d v4), 출력 전 검사, STL·3MF·STEP·GLB, 웹(정적)·Windows 설치 프로그램 |

## 1단계 — 부품 설계 핵심 (출력용 부품 대부분)

| 순서 | 기능 | 메모 |
|------|------|------|
| 1 | **피처 트리**: 만든 순서 목록, 앞 단계 수정·끄기·켜기, 실패한 피처 표시 | 설계 원본은 이미 명령 결과(파라메트릭)라 표시·억제(suppress)부터 |
| 2 | **회전(revolve)**: 스케치를 축 둘레로 (각도) | 컵·손잡이·노브 |
| 3 | **쉘(속 비우기)**: 벽 두께, 뚫을 면(이름 있는 면) | 상자·케이스 |
| 4 | 원하는 모서리만 필렛·모따기 | 모서리도 "이름 있는 모서리" 방식 (면 위 스케치와 같은 원리) |
| 5 | 패턴(직선·원형)·대칭 | 구멍 여러 개, 대칭 부품 |
| 6 | 스케치 2단계: 호·직선 요소, 각도 구속, 뷰포트에서 꼭짓점 끌기, 구속 기호 표시, 충돌 구속 진단 | `docs/review-constraint-solver.md` 7장 |
| 7 | STEP 가져오기, 무게·부피·무게중심 | 재질 밀도 |

**웹 엔진 결정**: manifold(메시)로는 회전 외의 쉘·임의 모서리 필렛·스윕을 정확히 못 한다 → 웹에서도 **OCCT 브라우저판(opencascade.js 계열, LGPL)**
을 쓰는 방향을 1단계 3번 전에 시험(크기·속도·라이선스 고지). 실패하면 해당 기능은 서버/데스크톱 엔진에서만 지원하고 웹에서는 안내.

## 2단계 — 조립과 도면

- 조립: 여러 부품 + 결합 조건(면 일치·축 일치·거리), 간섭 검사.
- 2D 도면: 투상도·단면·치수 → PDF/DXF. FreeCAD TechDraw(LGPL) 라이브러리 활용 검토.
- 스윕·로프트, 나사(규격 구멍·탭) 마법사.

## 3단계 — 자유 모델링 (블렌더 영역)

- 메시 편집(정점·변·면 선택과 이동), 서브디비전(매끄럽게), 조각(sculpt) 기초.
- CAD 원본과 메시는 **다른 원본**: CAD → 메시는 "굽기"(한 방향), 메시 편집이 CAD 피처를 덮어쓰지 않는다 (`docs/plan-sketch-extrude.md` 원칙).
- 재질·조명·사실적 렌더: 설치된 블렌더를 엔진처럼 호출(`blender --background`, GPL — 별도 프로그램)하거나 Three.js 경로 추적.

## 4단계 — 해석·움직임

- 강도 해석: FreeCAD FEM + CalculiX(GPL) 를 격리 워커로 호출, 결과 색으로 표시.
- 조립품 움직임 미리보기, 간단한 애니메이션(GLB).

## 진행 방식

단계마다: 설계 메모 → 스키마(Zod → Pydantic) → 두 엔진 + 공유 픽스처 → UI → AI(프롬프트·검증기·평가 케이스) → E2E·Windows CI → 문서.
